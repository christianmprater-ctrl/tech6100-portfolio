CHRISTIAN PRATER - PORTFOLIO SITE
=================================

Folder layout
-------------
portfolio/
  index.html        <- the whole website (open this in your browser)
  audio/            <- your music files
  images/           <- hero image + gallery artwork

Films are YouTube links, so there is no films folder: they are pasted into index.html.

Where to edit (open index.html in a plain-text editor such as VS Code or Notepad,
NOT Word; then use Ctrl+F / Cmd+F to search):
  const TRACKS   - song titles + audio filenames (+ optional cover art per track)
  const FILMS    - film titles + YouTube links
  const GALLERY  - artwork filenames, titles, captions
  --hero-image   - hero background image filename
  hello@example.com - your contact email (search for it)

After saving, refresh the browser tab to see changes.
Keep the folder together: if you move or upload the site, move the whole folder.
